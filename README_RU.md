Generative Language Model (GLM) — это исследовательский проект, посвящённый созданию генеративной языковой модели на основе динамически растущего графа концептов.

В отличие от традиционных LLM (Transformer), которые используют фиксированную топологию и градиентный спуск, Gen-LM исследует альтернативный подход:

Слияние (Merge): семантически близкие узлы объединяются в концепт более высокого уровня (energy+1).

Рост (Growth): новые узлы рождаются из конфликтов контекста.

Деградация (Shatter): замороженные концепты могут распадаться обратно на составляющие.

Все симуляторы работают прямо в браузере, используя Transformers.js для загрузки реальных нейросетевых эмбеддингов (MiniLM, NLLB-200), и не требуют серверной части.

📂 Структура проекта (/HTML5)
Каждый файл — это самостоятельный интерактивный эксперимент. Просто откройте нужный .html в браузере (или перейдите по прямой ссылке GitHub Pages).

1. AI_translate.html — Семантический переводчик
Что делает: Переводит текст с одного языка на другой (поддерживается 200+ языков через NLLB-200) и показывает «семантическое совпадение» между оригиналом и переводом в процентах.
Зачем: Демонстрирует, как эмбеддинги позволяют оценить качество перевода без эталонного текста, а также даёт утилитарный инструмент для быстрого перевода.

2. Black Box Puzzle.html — Игра «Чёрный ящик»
Что делает: Пошаговая головоломка. Игроку даны два слова (например, apple и banana), и он должен подобрать слово-мост (например, fruit), чтобы нейросеть «слила» их в один концепт.
Зачем: В игровой форме показывает, как работает семантическое сходство и почему не все слова являются «мостами» между понятиями.

3. Feed the Brain.html — Симулятор роста графа
Что делает: Позволяет вводить слова или фразы, наблюдая, как они «слипаются» в концепты (E1, E2, E3) в зависимости от порога сходства.
Зачем: Наглядная визуализация механизма слияния (Merge) и рождения абстракций. Можно двигать ползунок порога и видеть, как меняется структура графа.

4. Multilingual Sandbox.html — Мультиязычная песочница
Что делает: Показывает, как одна и та же сущность на разных языках (например, apple, яблоко, pomme) сливается в один узел.
Зачем: Демонстрация того, что языки — это лишь разные оболочки для одних и тех же смыслов (концептов). Полезно для изучения лексики и понимания работы мультиязычных моделей.

5. game.html и game_2.html — Ранние прототипы
Что делает: Более простые версии интерактивных графов (с физикой и волнами активации).
Зачем: Сохранены как история развития проекта и для сравнения с более поздними версиями.

6. SemanticChain.html — Семантическая цепочка (Игра)
Что делает: Пошаговая головоломка в стиле «Теории шести рукопожатий». Игроку даются два семантически далеких слова (например, луна и банан). Задача — соединить их, вводя промежуточные слова-мосты. Каждое новое слово должно быть близко по смыслу к предыдущему (порог сходства > 0.50), а последнее — к целевому.
Зачем: Показывает, как нейросеть выстраивает неочевидные смысловые связи между понятиями, которые в реальной жизни никак не связаны. Игра поддерживает два языка (RU/EN) и использует мультиязычную модель, позволяя вводить слова на любом из них. Отличный пример «черного ящика»: игрок должен эмпирически угадать, какие ассоциации модель считает валидными.

🛠️ Технологии
HTML5 / CSS3 / JavaScript (ES6 Modules)

Transformers.js (Hugging Face) — запуск моделей (Xenova/all-MiniLM-L6-v2, Xenova/nllb-200-distilled-600M) прямо в браузере.

Canvas API — визуализация графов и физика узлов.
